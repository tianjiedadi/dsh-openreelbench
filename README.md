## 我们为什么做它

大语言模型会写,ComfyUI 会画,配音模型会说——可是从「一句话」到「一部能看的片子」,中间隔着几十次往返:
写什么、配什么图、先出哪个、谁说了算、出了错谁来兜。

OpenReelbench 想做的,就是把这段路铺平。它是 [DeepSeek Harness](https://github.com/fandc520/dsh) 的开源创意插件:
你说出想法,AI 把它变成一部完整的解说片;而创作的主导权,始终握在你手里。

我们相信开源生态从不缺生成能力,缺的是把这些能力组织成**创作**的骨架。
OpenReelbench 是这个方向的一次认真尝试——用人工智能的潜力,为开源生态注入创意力量。

## 一条受管的创作流水线

四段状态机,两道人工闸。推不动的地方,是真的推不动——每一关,都由你亲自放行:

```
简报 ──〔你确认〕──> 脚本 ──〔你确认〕──> 配音 · 配图 ──> 合成
```

图像、配音、配乐由 [dsh-comfyui](https://github.com/fandc520/dsh-comfyui) 的 ComfyUI 工作流生成,组装由 FFmpeg 在本地完成。
你不必打开一次 ComfyUI 界面,也不必写一条 ffmpeg 命令。对 Agent 而言,这一切收敛为五个工具:
项目、状态机、合成、预览、剪辑——能力有了边界,创作才没有后顾之忧。

### 立项 —— 从一句话到一份创作意图

一切从一个念头开始。你说出它,AI 和你一起把它聊成一份简报:主题是什么、讲给谁听、时长几何、
用什么风格说。项目就此立项——往后的每一份素材、每一次状态、这部片子的全部家当,都在这一步安家。
想法还没聊透?没关系,换个方向重来是流水线的常态,不是事故。

### 脚本 —— 分段即分镜

脚本不是一篇流水文。它被切成一段一段,每一段就是将来的一格画面;每段写多长,由风格自带的
语速档说了算。画面提示词只写看得见的东西——光线、构图、动作,不写形容词堆出来的空话。
初稿不满意就改,改到满意为止。但请注意:脚本没有你的确认,管线一步都不会往前走。

### 配音 —— 让片子开口说话

先挑一支音色:从工作流现成的音色里选,或让 AI 按你的描述设计一支新的。样音先行——
先听一小段,满意了再批量生成全片。所有配音一次生成完毕,时长以实测为准,绝不采信口头申报:
后面的时间轴和字幕,都按真实声音排布。

### 分镜 —— 让每一格画面有话说

镜头语言在这里落进画面:镜别、焦段、光线、景深,五层提示词层层递进。一份风格契约管住全片
画风——第一张图和第三十张图,来自同一个世界。配音先行、配图在后,批次井然,
ComfyUI 不必来回装卸模型,把时间都花在出图上。

### 合成 —— 从想法到成片,你只需要关心内容本身

时间轴按实测时长排布,字幕逐句对齐声音,配乐自动压到解说之下、响度对齐平台规范。
点下合成,拿走成片和字幕文件——不用打开 ComfyUI,不用写一条 ffmpeg 命令。
繁琐的都交给了管线,省下来的精力,请全部投给内容。

## 十一份技能,全程同行

管线之上,十一份内建技能陪跑全程——一半把关创意质量,一半配合具体创作:

| 把关创意 | 配合创作 |
|---|---|
| **自审协议** —— 提交之前,先按规矩自挑毛病 | **解说片总纲** —— 节点图与全局规矩 |
| **叙事结构** —— 因果链、钩子与整片弧线 | **简报 · 脚本 · 配音 · 分镜 · 合成** —— 五段各自的作业细则 |
| **镜头语言** —— 镜别、光线与高光镜 | **工具契约** —— 工具如何表现,报错如何处置 |
| **声音设计** —— 选曲的两条硬规矩 | |

## 安装

本地修改版的预编译插件包为 `dsh-openreelbench-0.1.0-alpha.11.tgz`。在 DSH 的插件管理界面
填写 TGZ 的完整路径即可安装。桌面版、Web profile 的详细步骤见 [安装说明](INSTALL.md)。

支持 xAI / Grok Imagine 视频协议：自动识别模型，支持一张本地参考图、480p / 720p 选择、任务查询和鉴权下载。火神及兼容中转站配置见安装说明。

- **DeepSeek Harness 0.2.0-rc.2**、Node ≥ 22.19、PATH 上的 `ffmpeg` / `ffprobe`
- **搭档插件（可选）**:[dsh-comfyui](https://github.com/fandc520/dsh-comfyui) ≥ 0.4.0 —— 使用 ComfyUI 提供方时安装并在面板里备好工作流

```sh
npx -p @deepseek-ai/dsh@0.2.0-rc.2 dsh plugin --profile <你的非 desktop profile> add "<插件 TGZ 的完整路径>"
```

装完重启 profile。配置在「设置 → OpenReel 创意台」,或 `cordis.yml` 的 `openreel` 层——
绑定表里只写工作流的**名称**,怎么调由工作流自己的参数清单说了算。
更多细节见 [插件开发标准](docs/PLUGIN_DEVELOPMENT.md)。

### 生成提供方

配音页和分镜页都有「生成方式」选择：**ComfyUI** 或 **API 模型**。API 模式不经过 Agent，
由插件直接调用配置的 HTTP 接口并把返回文件写入项目资产目录；完成后仍然走原来的 manifest、
审批闸和 FFmpeg 合成流程。分镜页在 API 模式还可以选择输出图片或视频，视频会作为 `video` 资产
进入同一条时间轴。

在配音页或分镜页选择 API 后，可直接填写 API 地址、模型和 Key 并点击「保存 API 设置」。
这些表单与设置页「生成提供方与 API」共用配置，保存后立即生效，修改其他字段会保留已保存的 Key。
API Key 也可通过环境变量名配置。图片、视频、语音都支持自己的中转站地址与 Key。
地址可填写完整生成接口，也可填根地址或 `/v1`；插件仅为这些明确的根路径补全常见接口。
自定义视频接口请按中转站文档填写完整地址。

三类模型都有下拉选择和「获取模型」。已保存的接口打开时自动查询，新地址与 Key 可以先查询、
选择模型再一起保存。默认推导 `/models`，也可指定 `modelsUrl` 完整 GET 地址。
列表按用途筛选；中转站使用自定义模型名称时可切换「显示全部模型」，或启用「手动填写模型」。
筛选依据接口元数据或名称，不代表服务商一定已开通对应生成通道。查询失败会显示原因，并保留配置。

接口使用 JSON POST，文生图/文生视频接受 `prompt`、`model`、`width`、`height`、`size` 和时长字段；
语音接受 `input`/`text`、`voice`、`model`。响应支持直接媒体、`url`、`data[0].url`、`b64_json`、
`base64` 等常见格式。异步视频接口再填写 `pollUrl`，其中 `{id}` 会替换成任务 id。

### API 生成尺寸和视频时长

分镜页选择 API 后，「分镜生成」中可以选择常用尺寸或「自定义宽高」，填写模型支持的宽、高像素。
图片和视频分别保存在当前项目，点「保存生成参数」后使用。默认跟随成片尺寸；「恢复默认」再保存可恢复跟随。
自定义尺寸按原值发送，前后端都会拒绝空值、小数或不在 1–16384 范围内的宽高，具体尺寸仍需符合中转站模型要求。

顶部同时显示生成尺寸和成片尺寸。如果两者比例不同，页面会提示合成时按风格裁切或留边。
视频可勾选「固定视频生成时长」并填写模型支持的秒数，例如 4、8 或 12；不勾选时按各镜计划时长请求。
生成时长与时间轴上的镜头占比各自有用途，合成仍按配音与镜头计划排时间。

工作流选择、ComfyUI 参考图和 LoRA 参数区只在 ComfyUI 模式显示。
编辑已有 API 分镜的占比或顺序时，保留资产的模型、尺寸和来源信息。

### 可选：百炼原生语音

语音默认使用通用 / 中转站协议。选择「阿里云百炼原生」时，插件使用原生千问 TTS 接口，
不用另开本地桥接。地址留空使用北京地域，也可填写专享域名或完整原生接口。
兼容模型接口若未返回本插件支持的 TTS 模型，会显示**内置官方语音目录**并标注来源；
该目录不代表账号实时可用模型。目录只提供此适配器支持的同步千问 TTS，不混入聊天、实时 TTS 或 CosyVoice。

内置音色可选 `Cherry`、`Ethan`、`Serena`，也可粘贴已复刻音色 ID。使用参考音频时只保留一段，
首次生成自动调用 `qwen-voice-enrollment`，并使用 `qwen3-tts-vc-2026-01-22`（或已配置的 VC 快照）。
缓存位于当前项目的 `assets/voice-clones.json`，按音频内容、模型、服务和账号区分；不存 Key 或音频内容。
可关闭缓存，也可指定 `enrollmentEndpoint` 自定义声音复刻接口。`instructions` 仅用于 Instruct 系列。
音频按实际文件头识别扩展名，落盘前修复 WAV 占位长度，供 FFmpeg 正常测量时长。

## alpha.6：小说导入与 API 参考素材

首页和立项页支持 TXT / MD 小说导入，识别章节并自动生成可编辑的分段脚本、分镜计划。先预览章节、字数、段数、镜数和预计时长，再确认立项及脚本。支持 UTF-8、GBK / GB18030 和带 BOM 的 UTF-16；长篇可分章节建项目，保留源文本。

API 模式提供文生图 / 图生图、文生视频 / 参考图或视频生成；支持项目上传、预览、移除选择和公开素材地址。JSON、multipart 协议及字段可配置，图片参考默认使用 images/edits。KKRICH Seedance 按公开协议适配任务提交、查询、鉴权下载、模型限制及 HTTPS / assetId 参考素材。此站 Seedance 不接受本地文件或 Base64，需公开素材地址或平台签发 ID。

使用步骤及限制见 [安装说明](INSTALL.md)。本版适配 DSH 0.2.0-rc.2，提供预编译 TGZ。
